> **Project:** AI-Based Interview Preparation Assistant  
> **Course:** AI252TA – Machine Learning Operations | Semester V  
> **Status:** Phase 0 / Phase 1 Inception  

---

## 1. Directory Purpose

This directory maintains comprehensive documentation regarding dataset acquisition, data profiling, annotation guidelines, privacy evaluations, and DVC storage configurations.

---

## 2. Planned Documentation Modules

The following documents will be populated during Phase 1:

- **`dataset_selection.md`:** Evaluation matrix of candidate datasets, comparison of public benchmarks vs synthetic interview datasets.
- **`data_annotation_rubric.md`:** Standardized grading rubric defining boundaries between Poor (0), Needs Improvement (1), Good (2), and Excellent (3).
- **`data_provenance_sheet.md`:** Datasheet for Datasets detailing data collection methodology, licensing, and consent.
- **`dvc_storage_guide.md`:** Instructions for configuring and pulling versioned datasets from remote DVC storage.
